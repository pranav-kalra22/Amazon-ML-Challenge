# Evidence Discipline Rule (Always-On)

To maintain absolute scientific and engineering rigor, all findings, claims, and reports must adhere to this evidence discipline:

1. **Mandatory Evidence Classification**:
   Every claim, measurement, and reported number must be explicitly classified as one of:
   - **`[FULL-DATA MEASUREMENT]`**: Measured over the complete relevant population (e.g., all 2,206,821 Source 1 training entities or all 12.5M train records). State total $N$.
   - **`[VALIDATION MEASUREMENT]`**: Measured on a defined, leakage-safe held-out validation population with documented seed and S1 entity IDs. State validation $N$.
   - **`[SAMPLE MEASUREMENT]`**: Measured only on a sample. State the exact sample size $N$ (e.g., $N = 6,865$ ground truth pairs). Never silently extrapolate a sample finding to the entire population.
   - **`[HYPOTHESIS]`**: An untested conjecture, theoretical intuition, or proposition pending experimental verification.
   - **`[TARGET]`**: An aspirational objective or threshold (e.g., target Macro $F_{0.5} \ge 0.985884$), not yet established by measurement.

2. **No Silent Extrapolation**:
   - Never claim France performance or behavior from training evidence, as France appears strictly in the test set.
   - Never state that a strategy has "zero test recall loss" unless test labels actually exist.
   - Never generalize an error rate or recall metric from a sample without noting the sample boundaries.

3. **Experiment Attribution**:
   - Every metric reported in discussions or reports must link to an explicit `experiment_id` logged in `experiments/experiment_log.csv`.
   - Never label a modification as an "improvement" without a direct, side-by-side metric comparison against the current best baseline on the exact same validation split.

4. **Reproducibility**:
   - All numbers must be generated by runnable, deterministic Python scripts.
   - Record random seeds, data versions, and hyperparameters for every reported score.
